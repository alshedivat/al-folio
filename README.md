# Pratyush Varshney Website

This repository contains my personal website and technical blog built with Jekyll and the `academicpages` theme.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Then open:
- http://127.0.0.1:4000/

## Content structure

- `_pages/` static pages (About, Resources, Projects, Experience, Education)
- `_posts/` blog posts
- `_projects/` project collection items
- `_experience/` experience collection items
- `_education/` education collection items
- `assets/` images and static assets
- `images/` profile and theme image assets
