#### AI-supported Holographic Environmental Water Monitoring

**Funding:** [Vienna Science and Technology Fund WWTF](https://www.wwtf.at/index.php?lang=EN) (2025-2029)  
**Start Date:** 2025  
**Description:** This project combines **holographic microscopy and AI** to analyze turbidity in drinking water by identifying particles like sediments, plastics, algae, and bacteria. Using **IoT tools and digital twin technology**, it enables real-time monitoring and early detection of changes in water quality, improving decision-making and response times.  
**Principal Investigator:** [Peter Van Oostrum](https://boku.ac.at/personen/person/04B16CC604B8D118), **Co-PI:** [Ivona Brandić](https://www.ec.tuwien.ac.at/~ivona/)  
[More Info](https://www.wwtf.at/funding/programmes/esr/ESR24-053/index.php?lang=EN)

#### Themis - Trustworthy and Sustainable Code Offloading

**Funding:** [FWF](https://www.fwf.ac.at/en/) Standalone Project (2024-2027)  
**Start Date:** May 2024  
**Description:** Themis explores **probabilistic operating systems** to enable **dynamic code offloading**, allowing IoT devices to shift tasks to **idle nodes, edge devices, or other computational resources**. By integrating **edge computing** with large-scale **real-time probabilistic systems**, it aims to improve **efficiency and responsiveness** in applications such as **traffic management, quantum computing, and Microgrids**.  
**Project Coordinator:** [Ivona Brandić](https://www.ec.tuwien.ac.at/~ivona/)  
[More Info](https://hpc.ec.tuwien.ac.at/themis/)

#### Satellite-based Monitoring of Livestock in the Alpine Region (Virtual Shepherd)

**Funding:** [FFG](https://www.ffg.at/en) [Austrian Space Applications Programme ASAP](https://www.ffg.at/en/program/austrian-space-applications-programme-0) 2022 (2023-2025)  
**Start Date:** 2023  
**Description:** Virtual Shepherd integrates **satellite-based positioning, edge computing, and geospatial AI** to support sustainable livestock grazing in the Alpine region. Using **GNSS, LoRaWAN, and 4G/5G**, it enables **fenceless farming**, allowing cattle to be guided via smart collars while minimizing conflicts between hikers and livestock. Edge computing processes data locally, reducing bandwidth use and improving system resilience in challenging alpine conditions. The system also detects anomalies in cattle movement, alerting farmers to potential health issues or predator threats.  
**Project Coordinator:** [Johannes Scholz](https://www.johannesscholz.net/index.html), **Co-PI:** [Ivona Brandić](https://www.ec.tuwien.ac.at/~ivona/)  
[More Info](https://projekte.ffg.at/projekt/5122077)

#### Triton - Transprecise Edge Computing

**Funding:** [FWF](https://www.fwf.ac.at/en/) Standalone Project (2023-2027)  
**Start Date:** June 2023  
**Description:** Triton develops **transprecision computing** methods to improve **energy efficiency and performance** in edge computing. By dynamically adjusting computational precision, it enables **resource-efficient processing** for applications like **augmented reality and smart traffic systems**, where large data volumes must be handled with minimal latency. The project also explores **hybrid architectures**, integrating edge computing with **quantum systems** to enhance computational efficiency.  
**Project Coordinator:** [Ivona Brandić](https://www.ec.tuwien.ac.at/~ivona/)  
[More Info](https://hpc.ec.tuwien.ac.at/triton/)
